# Retro Game Hobby Website

This project will consist of creating a two page static website that focuses on retro game systems.  There will be an emphasis on the unique attributes of older systems such as the Atari 2600. The site will include a homepage describing the hobby and its appeal, and an About page providing background on retro gaming. This repository includes the full project package: scope, plan, and a retrospective. The project serves as a prototype for a website to provide detailed information on retro game systems.
