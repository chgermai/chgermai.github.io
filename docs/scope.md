# Project Scope Statement — Project 03

## **Project Name:** Retro Game Hobby Website  
**Project Manager:** Chris Germain  
**Date:** April 26, 2026  

| |  |
| - | - |
| **Project Purpose** | The purpose of this project is to design and deliver a simple website that introduces views to and explains the hobby of retro game systems, such as the Atari 2600. |
| **Description** | This project will consist of creating a static pages that will make up a website focused on retro game systems.  There will be an emphasis on the unique attributes of older systems such as the Atari 2600. The site will include a homepage describing the hobby and its appeal, and an About page providing background on retro gaming. All project documentation, including planning documentation will be stored in a single public GitHub repository. |
| **Desired Results** | <ul><li>A live and accessible static website</li><li>Complete documentation descibing the project, purpose, and planning.</li><li>A professional GihHuib respoistory meeting organizational requirements</li></ul> | 
| **Exclusions** | <ul><li>Downloadable Games</li><li>Emulators or ROM images</li><li>Dynamic Functionality</li><li>Database services</li></ul> |
| **Feedback Loops** |  Feedback will be captured throughout the project to ensure stakeholder alignment.  Team accountability sessions will be schedule on a bi-weekly basis. |
| **Resources** | <ul><li>A GitHub repository used for version control</li><li>GitHub Pages for hosting the website components.</li><li>Project Documentation in markdown</li><li>HTML and CSS for website components</li></ul> |
| **Priorites** | <ul><li>A clear and well defined scope</li><li>Clear and professional documentation</li><li>Adherence to project timelines</li><li>Technical accuracy and usability</li></ul> |
| **Acceptance Criteria** | <ul><li>GitHub Repository is publicly accessible and well organized</li><li>Documentation is complete</li><li>Navigation links work as expected</li><li>CSS attributes are applied to webpages</li><li>Overview of at least two retro game systems completed</li></ul> |
