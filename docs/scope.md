# Project Scope Statement

**Project Name:** Retro Game Hobby Website  
**Project Manager:** Chris Germain  
**Date:** May 8th, 2026  

## Project Purpose
The purpose of this project is to design and deliver a simple website that introduces viewers to and explains the hobby of retro game systems, such as the Atari 2600.

## Description
This project will consist of creating a two page static website that focuses on retro game systems.  There will be an emphasis on the unique attributes of older systems such as the Atari 2600. The site will include a homepage describing the hobby and its appeal, and an About page providing background on retro gaming. All project documentation, including planning documentation will be stored in a single public GitHub repository.

## Desired Results
- A live and accessible static website
- Complete documentation describing the project purpose and planning
- A professional GitHub repository meeting organizational requirements

## Exclusions
- Downloadable games
- Emulators or ROM images
- Dynamic functionality
- Database services

## Feedback Loops
Feedback will be captured throughout the project to ensure stakeholder alignment. Feedback will be included via self-review and peer review.  Changes will be incorporated to improve clarity and usability.

## Resources
- A GitHub repository used for version control
- GitHub Pages for hosting the website components
- Project documentation in markdown
- HTML and CSS for website components

## Priorities
- A clear and well-defined scope
- Clear and professional documentation
- Adherence to project timelines
- Technical accuracy and usability

## Acceptance Criteria
- GitHub repository is publicly accessible and well organized
- Documentation is complete
- Navigation links work as expected
- CSS attributes are applied to webpages
- Overview of at least two retro game systems (Atari 2600 & NES) completed
