# Project Retrospective — Retro Game Hobby Website

## What Went Well
Using a simple two page static webpage design simplified the requirements for the prototype.  This in turn made it easier to complete the project without introducing scope creep within the planned time frame.  Starting with documentation provided a framework to complete the tasks and make sure I met all requirements.

## What Went Wrong
I initially had issues getting the heading to be uniform on different devices.  However, after some research I found a method to provide a navigation bar for each page that could then be uniformly applied.   

## What I Would Do Differently Next Time
I feel I would have been better served to complete the minimum viable product (MVP) of the site sooner and allow more time for personal feedback. It would also have been helpful to include a checklist, from the start, in the plan to make sure all items were completed rather than going back to the original documentation.  The checklist needs to be a complete listing of all minimum requirements.
